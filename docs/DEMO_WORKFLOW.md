# Suggested Hackathon Demo

1. Sign in as organizer.
2. Create an event or use the seeded College Innovation Hackathon.
3. Sign out; register/login as participant and register for the event through the API.
4. Create a team as a registered participant.
5. Check in using the generated participant code from `/api/participants/{event_id}/my-pass`.
6. Publish an announcement as organizer.
7. Submit a project as team leader.
8. Sign in as judge and score the submission.
9. Open Leaderboard and Audit Logs as organizer.

API docs at `/docs` make it easy to demonstrate endpoints live.
